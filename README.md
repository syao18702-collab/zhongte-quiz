# 《习近平新时代中国特色社会主义思想》502题网页版刷题系统

根据用户提供的 **总论100题.xlsx** 和 **分论402题.xlsx** 原样导入题目、A-D选项、答案与解析，共502题；额外从分论Excel提取47组易混知识点。借鉴提供的四川省情微信小程序V1.3交互规则，实现可手机浏览的静态网页。

## 功能

- 16专题刷题：总论100题 + 分论15专题402题。
- 普通练习：四选一；选完点“提交答案”显示绿色/红色和解析，支持上一题、下一题、答题卡任意跳题，切题状态保持并在浏览器断点保存。
- **手机左右滑动切题**：在题目区域向左滑下一题、向右滑上一题；水平位移超过65px且明显大于垂直位移才触发，以免影响竖向滚动。
- 答题卡：白=未答；黄=选择但未交；绿=答对；红=答错；深蓝外框=当前题。模拟考试不显示正误，仅蓝=已答。
- 随机20题、核心必刷（按题库“辨析强化”等已有元数据筛选，不声称等价于原思维导图彩色字体）、错题本、收藏、速记卡、47组易混对照。
- 错题规则：答错自动加入，任意普通练习累计连续答对3次后自动移出并记录已掌握。
- 模拟考试：默认全题库随机50题/30分钟，允许设置调整；交卷前确认未作答数量，按时间戳计算倒计时，时间到自动交卷，成绩历史保存，考试中的题目不泄露答案。考试分数独立统计，不混入普通练习次数。
- 本地持久化 `localStorage`，可导出/导入JSON备份，考试日期倒计时、统计页面。

## 直接部署到 GitHub + Vercel

1. 解压压缩包，进入 `中特网页版刷题程序` 文件夹，确保根目录可见 `index.html`、`app.js`、`styles.css`、`data/`、`vercel.json`。
2. 在 GitHub 创建一个**新仓库**，通过网页 `Add file → Upload files` 上传**该文件夹内部所有文件（含data目录）**，提交。推荐不要上传自己的学习备份JSON。
3. 打开 [vercel.com](https://vercel.com/) 登录 → **Add New → Project** → **Import Git Repository**，选择该仓库。
4. **Framework Preset** 选择 `Other`，**Root Directory** 使用仓库根目录；无需环境变量、无需安装依赖、无需构建指令。点 **Deploy**。
5. 部署后打开 Vercel 提供的 `.vercel.app` 地址，手机浏览器即可刷题；在手机浏览器里可使用“添加到主屏幕”快捷打开（不依赖微信小程序权限）。
6. 之后更新题库或源码，只需向 GitHub push，Vercel 会自动重新部署。

> 这里提供的是部署就绪的源代码压缩包，不会替你自动创建 GitHub 仓库、关联 Vercel 或发布公网地址。

## 本地预览

需通过HTTP服务器访问，否则双击 `index.html` 时浏览器可能禁止读取JSON。

```bash
python -m http.server 8080
```

打开 http://localhost:8080/ 。也可使用 `npx serve .`（如本地已安装）。

## 数据与同步注意事项

- 完全静态，无账号体系、无数据库、不需要服务端。题库经网络第一次加载，浏览器在联网时访问；**不保证完全离线可用**。
- 练习记录仅存**当前浏览器与当前网址的 localStorage**，同一GitHub仓库部署到不同域名，记录不会自动迁移；手机电脑之间也不会自动同步，请在“设置 → 导出JSON备份”，另一设备“导入备份”。
- 题库 `data/questions.json` 保持原Excel表述，属于学习资料，未对每道题另行进行权威文献校验；历史或现行政策表述应在复习中对照权威文件核实。
- 原思维导图彩色文字的准确映射未包含在 Excel 数据里，因此“核心必刷”仅根据表格已有层级标签选题，而非依据颜色进行精确筛选。
- 外部库0个，无npm依赖，适合免费静态部署。
